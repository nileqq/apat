Бүгінгі мақаланың кейіпкері – Илья. Илья бүгін бөліскен бұл тарих оның отбасында тек үзінді түрінде сақталған. Уақыт өте келе арғы атасының тағдыры туралы көптеген егжей-тегжейлер ұмытылған, сондықтан бұл толық әңгімеден гөрі, ұрпақтан ұрпаққа берілген естеліктерге көбірек ұқсайды.

Дегенмен, осы бөлшектердің өзі мемлекетке адал болған, адал еңбек еткен, үлкен отбасы тәрбиелеген, бірақ бәрібір қуғын-сүргіннің құрбанына айналған адамның трагедиясын көруге жеткілікті. Сергей Измайлович Кудрявцевтің тағдыры қуғын-сүргін жылдарында ешқандай еңбек те, адалдық та, отбасының кеңес мемлекетін құруға қатысуы да бассыздықтан қорғай алмағанын еске салады.

1920-1950 жылдардағы Қазақстандағы саяси қуғын-сүргін – бұл зиялы қауымды жаппай жою, кәмпескелеу, 1,5 миллионға жуық адамның өмірін қиған қолдан жасалған ашаршылық және тұтас халықтарды жер аудару. Тоталитарлық режимнің құрбаны миллиондаған адам болды, ал Қазақ КСР-інде сотталғандардың жалпы саны 100,000-нан асты.

Қуғын-сүргін «Алаш-Орда» партиясының көшбасшыларын (Әлихан Бөкейханов, Ахмет Байтұрсынов, Міржақып Дулатов), ғалымдарды, жазушыларды және қоғам қайраткерлерін қамтыды.

Бұл қуғын-сүргіндерді тек тәуелсіз қазақ мемлекетін құруға ұмтылған адамдарды қудалау ретінде ғана емес, сонымен бірге Қазақстанның интеллектуалды және мәдени мұрасын жою ретінде де қарастыруға болады. Қазақ зиялылары (сол кездегі қоғамның ең білімді бөлігі) білім беру, ана тілін сақтау, ағартушылық пен реформалар арқылы өз халқын дамытуға ұмтылды. Алайда сталиндік режим осы интеллектуалды элита өкілдерін жаппай репрессияға, азаптауға және атуға ұшыратып, қоғамды ұлттық көшбасшы атанып, дамудың басқа жолын ұсына алатын адамдардан айырды. Осылайша кеңес өкіметі ықтимал қарсылық ошақтарын жойып, өңірдегі өз бақылауын нығайтты.

Қазақстан территориясында ең ірі лагерьлер де орналасты: АЛЖИР (Отанға опасыздық жасағандар әйелдерінің Ақмола лагері), Карлаг (Қарағанды ЕТЛ) және Степлаг, бұл жерлерге бүкіл КСРО-дан тұтқындар жер аударылды.

## Өзі туралы

}

## Арғы атаның тағдыры

@Автор {
    Сіздің арғы атаңыз кеңес өкіметі тарапынан репрессияға ұшырады. Ұсталғанға дейін ол қандай адам еді?
}

@Илья {
    Меңің арғы атам, Кудрявцев Сергей Измайлович, 1905 жылы туған. Әжемнің естеліктері бойынша, ол қатал, бірақ өте жауапты әрі еңбекқор адам болған. Сонымен қатар оның көптеген таланты бар еді: ол гитарада, мандолинада, балалайкада және фортепианода ойнауды өздігінен үйренді.
    Тұтқындалғанға дейін арғы атам инженер болып жұмыс істеді, ойлап тапқыш-рационализатор және қалалық су құбырының директоры болды. Ол бес бала тәрбиелеп өсірді, айналасындағылардың құрметіне бөленді және кеңес өкіметіне шын жүректен адал болды.
    Оны қаншалықты бағалағаны туралы отбасында тағы бір эпизод сақталған. Әжем Киров атындағы зауытқа жұмысқа орналасқанда, кәсіпорын директоры Сутюшев (Мидхат Усманович болса керек) оны болашақ тойына міндетті түрде шақыруды өтінген, өйткені ол әкесімен бір үстелде отырғысы келген.
}

@Автор {
    Арғы атаңызға не болды?
}

@Илья {
    Жүйеге адалдығына қарамастан, арғы атам бәрібір мемлекеттік машинаның диірменіне түсті. Оны Алматы облысындағы лагерьге жіберді.
}

> «Сталиндік репрессия жылдарында Алматы облысында тұрақты түзету-еңбек лагерьлері (ГУЛАГ) болған жоқ, бірақ мұнда басты өткел-пайдалану пункті және жаппай ату орны болды. Ең қорқынышты нысан – Талғар ауданындағы Жаңалық өңірі (ауылы), онда атылған тұтқындар жасырын жерленген.»

@Илья {
    Әжемнің айтуынша, ол одан бір көзсіз және мертіккен аяқпен оралған.
    Тергеу кезінде оны «халық жауы» екенін мойындайтын қолхатқа қол қоюға мәжбүрлеген, бірақ ол бас тартқан. Кереметпен аман қалды. Кейін оны ақтады. Отбасында айтылғандай, бұған партия басшылығынан біреудің оны жеке танитыны себеп болған. Нәтижесінде арғы атам 69 жас өмір сүрді.
    Бұл тарихтың ең өкініштісі – оның әкесі Азамат соғысында Чапаев дивизиясы жағында соғысып, мәні ашылғанда, кейін өз отбасына қарсы шыққан соғыс жүйесін құруға қатысқан.
}

> «Василий Иванович Чапаев – Ресейдегі Азамат соғысының (1917-1922 жж.) ең танымал әскери қайраткерлерінің бірі, Қызыл армия командирі.»

@Автор {
    Арғы атаңыздың отбасы ол тұтқында болған кезде қалай өмір сүрді?
}

@Илья {
    Өкінішке орай, бұл кезең туралы біздің отбасымызда өте аз ақпарат сақталған. Меңің әжем 1945 жылы туған, сондықтан ол оқиғалардың куәсі болған жоқ және тек үлкендерден естігенін айтып беретін.
    Тек бір отбасылық оқиға есімде: арғы атам лагерьден оралғанда, оның анасы қуаныштан үстел басында қайтыс болған деседі. Бұл қаншалықты шындыққа жанасатынын білмеймін, бірақ біздің отбасымызда осылай айтылатын. Отбасын баспанасынан айырған жоқ, көшірген де жоқ.
}

@Автор {
    Арғы атаңызға қандай өнертабыстар немесе рационализаторлық ұсыныстар тиесілі?
}

@Илья {
    Менің білуімше, Қазақ КСР-індегі су құбырлары саласындағы өнертабыстар мен колонкаларды жетілдіру арғы атама тиесілі.
}

## Тарихи сабақ

@Автор {
    Арғы атаңыздың әкесінің Василий Иванович Чапаев дивизиясына қатысуы неліктен отбасын қорғай алмады?
}

@Илья {
    Бұл, сірә, ашық сұрақ болып қала береді. Мен тек болжай аламын, өйткені бізде обьективті деректер сақталмаған.
    Мүмкін, бұған қандай да бір ішкі күрес немесе біреудің жеке мүдделері себеп болуы мүмкін. Мысалы, белгілі бір лауазымды иелену немесе бәсекелесті жою қалауы. Бірақ күдік пен айыптаулар кез келген себеппен пайда болуы мүмкін болған сол кездегі жалпы атмосфераны да жоққа шығаруға болмайды.
    Арғы атамның тарихы бұрынғы еңбектердің, жүйеге адалдықтың және отбасының оның қалыптасуына қатысуының да адамды репрессиялық машинадан әрдайым қорғай алмағанын көрсетеді.
}

@Автор {
    Қазақстанның жас ұрпағына қандай жолдау жеткізгіңіз келеді?
}

@Илья {
    Біздің еліміз бен қоғамымыз үшін өткенді саралау және тарихи жадыны деколонизациялау процесін жалғастыру өте маңызды. Осы жылы Қазақстан тәуелсіздігіне 35 жыл толады, бірақ әлі күнге дейін миллиондаған адамдар төлеген бағаны ұмытып, тек оның жетістіктерін еске алып, коммунистік жүйенің қылмыстарын ақтауға тырысатын адамдар табылады.
    Бұл жүйенің қаншалықты өмірді қиғанын, қазақ халқына және Қазақстан территориясында тұратын басқа да этностарға қаншалықты қайғы-қасірет әкелгенін, біздің жерімізде қандай трагедиялар болғанын есте сақтау маңызды.
    Ашаршылық, Голощекиннің «Кіші Қазаны», жаппай репрессиялар, орыстандыру саясаты, Арал теңізінің тартылуы мен Семей полигонындағы сынақтар сияқты экологиялық апаттар, Желтоқсан оқиғалары, шешендерді, немістерді, корейлерді, балттарды және басқа да халықтарды депортациялау – осының бәрін білу және ашық айту қажет.
    Азаматтар бұл трагедияларға әкелген шешімдерді кім қабылдағанын, әділетсіздікке кім қарсы тұрғанын және Қазақстанның тәуелсіздікке қандай бағамен келгенін түсінуі тиіс.
    «Ешқашан қайталанбасын» деген сөз тіркесі тек Екінші дүниежүзілік соғыс трагедиясы мәнмәтінінде ғана айтылмауы керек. Ол адамзатқа қарсы жасалған барлық қылмыстарға қатысты болуы және мұндай сұмдықтың қайталанбауы тиіс екенін еске салып тұруы қажет.
}
